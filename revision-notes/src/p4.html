13Time Series Analysis

Big idea: ordinary ML assumes rows are I.I.D. (shuffle them and nothing changes). In a time series order is the information: today depends on yesterday.

  • No shuffled K-fold: a random split could train on 2026 to predict 2024 → leakage. Use a forward-chaining split (TimeSeriesSplit): train on 1..t, test on t+1..t+h, growing the window.
  • Classical models assume equally spaced time steps.

Components

Additive decomposition $$y_t = T_t + S_t + R_t$$

Trend T = long-term direction. Seasonality S = repeating cycles at a fixed, known period (weekend dips, summer AC sales). Noise / residual R = random, unpredictable. If a model's residuals look like pure noise, it has captured everything learnable.

Stationarity

Weak stationarity — all three must hold $$E[y_t] = \mu \ (\text{constant mean}) \qquad \text{Var}(y_t) = \sigma^2 \ (\text{constant variance}) \qquad \text{Cov}(y_t, y_{t-k}) = \gamma_k \ (\text{depends only on lag } k)$$

AR/MA models need stationary data. A trend breaks condition 1; growing spread breaks condition 2. (ADF test: null = non-stationary; p < 0.05 → stationary.)

Lags and differencing

Lag and differences $$\text{lag } k = y_{t-k} \qquad \Delta y_t = y_t - y_{t-1} \qquad \Delta_s y_t = y_t - y_{t-s}\ (\text{seasonal}) \qquad \hat y_{t+1} = y_t + \widehat{\Delta y}_{t+1}$$
Worked: series 10, 13, 15, 20
  1. First differences: 13 − 10 = 3, 15 − 13 = 2, 20 − 15 = 5 → [—, 3, 2, 5] (the first value is lost).
  2. Second difference (difference of the differences): 2 − 3 = −1, 5 − 2 = 3.
  3. Lag-1 column = [—, 10, 13, 15].

First differencing removes a (linear) trend; seasonal differencing (lag s) removes seasonality; log stabilises growing variance. "Last week" = lag 1 for weekly data, lag 7 for daily data.

AR(p) — Auto-Regression

AR(p) $$y_t = c + \phi_1y_{t-1} + \phi_2y_{t-2} + \dots + \phi_py_{t-p} + \varepsilon_t \qquad \text{AR(1) long-run mean } \mu = \frac{c}{1-\phi_1}$$

Regress the series on its own past p values. p too large (p = 365 for tomorrow's temperature) → 365 weights → slow, overfits noise.

Worked

AR(1): $y_t = 2 + 0.6y_{t-1}$, $y_{t-1} = 10$ → forecast 2 + 6 = 8 (forecast sets ε = 0); long-run mean = 2/(1 − 0.6) = 5.   AR(2): $5 + 0.5(20) - 0.2(10) = 5 + 10 - 2 = $ 13. Multi-step: earlier forecasts become the inputs.

ACF and PACF

Sample ACF at lag k $$\rho_k = \frac{\sum_{t=k+1}^{N}(y_t - \bar y)(y_{t-k} - \bar y)}{\sum_{t=1}^{N}(y_t - \bar y)^2} \in [-1, 1] \qquad \text{significance band } \pm\frac{1.96}{\sqrt N}$$
Worked: y = 1, 2, 3, 4, 5, lag 1
  1. ȳ = 3; deviations: −2, −1, 0, 1, 2. Denominator = 4 + 1 + 0 + 1 + 4 = 10.
  2. Pair each value with the one before it: (−1)(−2) + (0)(−1) + (1)(0) + (2)(1) = 2 + 0 + 0 + 2 = 4.
  3. $\rho_1 = 4/10 = $ 0.4.
  • ACF = total correlation with lag k (direct + "ripple" through the lags in between). ρ ≈ +1: today follows the past; ρ ≈ −1: mean-reverting.
  • PACF = direct correlation with lag k after removing the effect of the lags in between. (Day-before-yesterday → yesterday → today is a ripple; PACF removes it.)

MA(q) — Moving Average of shocks

MA(q) $$y_t = c + \varepsilon_t + \theta_1\varepsilon_{t-1} + \dots + \theta_q\varepsilon_{t-q} \qquad \varepsilon_t = y_t - \hat y_t \ (\text{shock / forecast error})$$

Uses past errors (shocks), not past values — not a rolling mean. e.g. $50 + \varepsilon_t + 0.5\varepsilon_{t-1}$ with ε_t = 2, ε_{t−1} = −4 → 50 + 2 − 2 = 50.

Memory aid: PACF → p (AR), ACF → q (MA). ARIMA(p, d, q): d = number of differences. A spike at lag 7 in daily data = weekly seasonality.

⚠ Exam traps
  • First differencing removes trend, not seasonality.
  • Stationarity ≠ constant values; it's constant statistical properties.
  • Noise (a component) vs a random shock (one specific unpredictable event).

14Maximum Likelihood Estimation & Logistic Regression

Probability vs likelihood

Same formula, different question

Probability: parameter fixed (p = 0.5), ask about data ("chance of 7 heads in 10?"). Likelihood: data fixed (we saw 7 heads), ask about the parameter ("which p explains this best?"). MLE: choose the parameter that makes the observed data most likely: $\hat\theta = \arg\max_\theta L(\theta; D)$.

Binomial likelihood $$L(p) = \binom{n}{k}p^k(1-p)^{n-k}$$
Worked: 7 heads in 10 tosses

$\binom{10}{7} = 120$. L(0.5) = 120 × 0.5¹⁰ = 0.117. L(0.7) = 120 × 0.7⁷ × 0.3³ = 120 × 0.0824 × 0.027 = 0.267 (largest). L(0.9) = 120 × 0.478 × 0.001 = 0.057. → p = 0.7 explains the data best.

Derivation — the Bernoulli MLE is p̂ = k/n
  1. $L(p) \propto p^k(1-p)^{n-k}$ the constant $\binom nk$ doesn't change where the maximum is
  2. $\ell(p) = \ln L = k\ln p + (n-k)\ln(1-p)$ take logs (the max is in the same place; products become sums): $\ln a^k = k\ln a$
  3. $\frac{d\ell}{dp} = \frac{k}{p} - \frac{n-k}{1-p}$ $\frac{d}{dp}\ln(1-p) = \frac{-1}{1-p}$ (chain rule)
  4. $\frac{k}{p} = \frac{n-k}{1-p}$ → $k(1-p) = (n-k)p$ set to 0, cross-multiply
  5. $k - kp = np - kp$ → $k = np$ → $\boxed{\hat p = k/n}$ the −kp cancels on both sides (7/10 = 0.7 ✔)

Logistic regression: score → probability

  • Accuracy is a step function (no gradient) and doesn't reward confidence. We need probabilities.
  • Linear score $z = \beta_0 + \beta_1x_1 + \beta_2x_2$ (any real number; not a probability). Decision boundary: z = 0 (a line/plane).
  • A step function (z ≥ 0 → 1) has zero gradient almost everywhere → can't learn. Use the smooth sigmoid.
Sigmoid $$\hat p = P(y = 1 \mid \mathbf x) = \sigma(z) = \frac{1}{1 + e^{-z}} \qquad P(y=0) = 1 - \hat p \qquad z = \ln\frac{\hat p}{1 - \hat p}\ (\text{logit})$$

σ(−z) = 1 − σ(z). Threshold 0.5 ⇔ z = 0. e.g. z = −1 + 0.5(2) + 0.25(4) = 1 → p̂ = 0.731 → class 1.

From likelihood to Binary Cross-Entropy (BCE)

Derivation — BCE is the negative log-likelihood
  1. One row: P(observed label) = $\hat p_i^{\,y_i}(1 - \hat p_i)^{1-y_i}$ if y = 1 → p̂ (the second factor becomes ^0 = 1); if y = 0 → 1 − p̂
  2. All rows (independent): $L(\boldsymbol\beta) = \prod_{i=1}^{n}\hat p_i^{\,y_i}(1 - \hat p_i)^{1-y_i}$ multiply the probabilities
  3. $\ell = \ln L = \sum_i\big[y_i\ln\hat p_i + (1 - y_i)\ln(1 - \hat p_i)\big]$ log of a product = sum of logs
  4. Maximise ℓ ⇔ minimise $-\ell$. Average over n: $\boxed{\text{BCE} = -\frac1n\sum_i\big[y_i\ln\hat p_i + (1 - y_i)\ln(1 - \hat p_i)\big]}$

Per row: y = 1 → loss = −ln p̂; y = 0 → loss = −ln(1 − p̂).

Worked: how BCE behaves (y = 1)

p̂ = 0.9 → −ln 0.9 = 0.105 (good). p̂ = 0.5 → 0.693. p̂ = 0.1 → −ln 0.1 = 2.303 (confidently wrong is very expensive). Two rows y = [1, 0], p̂ = [0.8, 0.3]: (−ln 0.8 − ln 0.7)/2 = (0.223 + 0.357)/2 = 0.290.

  • BCE is convex but has no closed form → train with gradient descent (Topic 15).
  • Regularised: J = BCE + λ·R(β). Large λ → underfitting.
  • Equal accuracy does not mean equal likelihood (confidence matters).
⚠ Exam traps
  • For a y = 0 row use 1 − p̂ (not p̂).
  • z is a score, not a probability. Use the natural log.
  • Log-likelihood −20 beats −35 (larger is better).

15GD on Logistic Regression & Multiclass

Big idea: the BCE gradient simplifies beautifully to (p̂ − y)·x — "error × input", the same shape as linear regression.

chain: $\beta_j \ \to\ z = \boldsymbol\beta^T\mathbf x \ \to\ \hat p = \sigma(z) \ \to\ L$    so    $\frac{\partial L}{\partial\beta_j} = \frac{\partial L}{\partial\hat p}\cdot\frac{\partial\hat p}{\partial z}\cdot\frac{\partial z}{\partial\beta_j}$

Link 1 — ∂L/∂p̂
  1. $L = -[y\ln\hat p + (1-y)\ln(1-\hat p)]$
  2. $\frac{\partial L}{\partial\hat p} = -\frac{y}{\hat p} + \frac{1-y}{1-\hat p}$ $\frac{d}{d\hat p}\ln\hat p = \frac1{\hat p}$; $\frac{d}{d\hat p}\ln(1-\hat p) = -\frac{1}{1-\hat p}$, and the two minus signs make it +
  3. $= \frac{-y(1-\hat p) + (1-y)\hat p}{\hat p(1-\hat p)}$ common denominator
  4. $= \frac{-y + y\hat p + \hat p - y\hat p}{\hat p(1-\hat p)} = \boxed{\frac{\hat p - y}{\hat p(1-\hat p)}}$ expand; +yp̂ and −yp̂ cancel
Link 2 — sigmoid derivative σ′ = σ(1 − σ)
  1. $\sigma(z) = (1 + e^{-z})^{-1}$
  2. $\sigma'(z) = -1\cdot(1 + e^{-z})^{-2}\cdot(-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2}$ power rule, then chain rule: derivative of $e^{-z}$ is $-e^{-z}$
  3. $= \frac{1}{1 + e^{-z}}\cdot\frac{e^{-z}}{1 + e^{-z}}$ split into two fractions
  4. $\frac{e^{-z}}{1 + e^{-z}} = \frac{(1 + e^{-z}) - 1}{1 + e^{-z}} = 1 - \sigma(z)$ add and subtract 1 on top
  5. $\boxed{\sigma'(z) = \sigma(z)\,(1 - \sigma(z))} = \hat p(1-\hat p)$ largest at z = 0: 0.5 × 0.5 = 0.25
Link 3 and the result
  1. $\frac{\partial z}{\partial\beta_j} = x_j$ $z = \beta_0 + \beta_1x_1 + \dots$; only the βⱼ term contains βⱼ (x₀ = 1)
  2. $\frac{\partial L}{\partial\beta_j} = \frac{\hat p - y}{\hat p(1-\hat p)}\cdot\hat p(1-\hat p)\cdot x_j$ multiply the three links
  3. $\boxed{\frac{\partial L}{\partial\beta_j} = (\hat p - y)\,x_j}$ the $\hat p(1-\hat p)$ cancels — so $\frac{\partial L}{\partial z} = \hat p - y$
  4. All n rows: $\boxed{\nabla J = \frac1n X^T(\hat{\mathbf p} - \mathbf y)}$,   $\boldsymbol\beta \leftarrow \boldsymbol\beta - \alpha\nabla J$ average over rows; 1/n, no factor 2 (unlike MSE)
Worked: one batch update (worksheet)

Rows (x = 1, y = 0) and (x = 2, y = 1); β₀ = β₁ = 0; α = 0.4.

  1. z = 0 for both → p̂ = σ(0) = 0.5, 0.5. Errors p̂ − y = +0.5, −0.5.
  2. $\partial J/\partial\beta_0 = \frac{(0.5)(1) + (-0.5)(1)}{2} = 0$; $\partial J/\partial\beta_1 = \frac{(0.5)(1) + (-0.5)(2)}{2} = \frac{-0.5}{2} = -0.25$.
  3. β₀ = 0 − 0.4(0) = 0; β₁ = 0 − 0.4(−0.25) = 0.10 (update both simultaneously).
  4. Check: new z = 0.1, 0.2 → p̂ = 0.525, 0.550. BCE: −ln(1 − 0.525) = 0.744, −ln 0.550 = 0.598 → mean 0.671 < 0.693 = ln 2 (the starting loss with β = 0). Loss fell ✔.

Multiclass: One-vs-Rest (OvR)

  • K classes → train K binary logistic models, each "class k vs everything else". Parameters = K(d + 1).
  • Predict: compute all K sigmoid scores, pick the largest. The K scores need not sum to 1.

Multiclass: Softmax (multinomial logistic regression)

Softmax and cross-entropy $$\hat p_k = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}} \qquad L = -\sum_{k}y_k\ln\hat p_k = -\ln\hat p_{\text{true class}} \qquad \frac{\partial L}{\partial z_k} = \hat p_k - y_k$$
Worked: logits (2, 1, 0)
  1. $e^2 = 7.389$, $e^1 = 2.718$, $e^0 = 1$ → sum = 11.107.
  2. p̂ = 7.389/11.107 = 0.665, 2.718/11.107 = 0.245, 1/11.107 = 0.090 (sum = 1 ✔).
  3. True class = 2nd → CE = −ln 0.245 = 1.41; if true = 1st → −ln 0.665 = 0.41.

Adding the same constant to all logits changes nothing → compute with $e^{z_k - \max z}$ to avoid overflow. Multiplying the logits does change the result. K = 2 softmax = sigmoid of $z_1 - z_2$.

Odds, log-odds, boundaries, regularisation

Odds $$\text{odds} = \frac{p}{1-p} \qquad \ln\frac{p}{1-p} = z = \beta_0 + \boldsymbol\beta^T\mathbf x \qquad \text{odds ratio} = e^{\beta_j}$$

p = 0.8 → odds 4 → log-odds ln 4 = 1.386. One unit more of xⱼ adds βⱼ to the log-odds (multiplies the odds by $e^{\beta_j}$) — not to the probability.

  • Assumptions: independent rows, log-odds linear in the features, little multicollinearity.
  • Linear z → straight boundary. Add x₁², x₂² → curved boundary (a circle/ellipse) — still logistic regression.
  • Regularisation: J = BCE + λΣβⱼ² (L2 adds 2λβⱼ to the gradient → shrinks big weights) or λΣ|βⱼ| (L1 → zeros). Scale features; don't penalise β₀. sklearn C = 1/λ.
⚠ Exam traps
  • The gradient is (p̂ − y)x when you subtract α × gradient. With (y − p̂) you'd go uphill.
  • The starting BCE with β = 0 is always ln 2 = 0.693.
  • OvR scores don't sum to 1; softmax probabilities do.
