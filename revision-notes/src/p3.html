9Bias, Variance & the Tradeoff

Big idea: a model's expected test error splits into three parts: Bias² (too simple) + Variance (too sensitive to the sample) + σ² (noise nobody can remove).

The setup

Data-generating model $$Y = f(X) + \varepsilon,\qquad E(\varepsilon) = 0,\qquad \text{Var}(\varepsilon) = \sigma^2 = E(\varepsilon^2) - [E(\varepsilon)]^2 = E(\varepsilon^2)$$

f = the true (population) function; ε = white noise → irreducible error. No model can remove it.

  • The fitted model $\hat f$ depends on which training sample you got → $\hat f(x)$ is a random variable (an estimator: sample mean, linear regression, decision tree…). Fit on many samples → many different $\hat f$'s.
Bias, variance, decomposition $$\text{Bias} = E[\hat f(x)] - f(x) \qquad \text{Var} = E\big[(\hat f(x) - E[\hat f(x)])^2\big]$$ $$\boxed{\text{MSE} = E[(Y - \hat f(x))^2] = \text{Bias}^2 + \text{Var} + \sigma^2}$$
Derivation of the decomposition (write $\hat f = \hat f(x)$, $\bar f = E[\hat f]$)
  1. $E[(Y - \hat f)^2] = E[(f + \varepsilon - \hat f)^2]$ replace Y by f + ε
  2. $= E[(f - \hat f)^2] + 2E[\varepsilon(f - \hat f)] + E[\varepsilon^2]$ expand $(A + \varepsilon)^2 = A^2 + 2A\varepsilon + \varepsilon^2$ with $A = f - \hat f$
  3. Middle term = $2E[\varepsilon]\,E[f - \hat f] = 2\cdot 0 \cdot(\dots) = 0$ new noise ε is independent of the trained model, and E(ε) = 0; last term = σ².
  4. $E[(f - \hat f)^2] = E[(f - \bar f + \bar f - \hat f)^2]$ add and subtract the average prediction $\bar f$
  5. $= (f - \bar f)^2 + 2(f - \bar f)E[\bar f - \hat f] + E[(\bar f - \hat f)^2]$ expand; $(f - \bar f)$ is a fixed number, so it comes out of E
  6. $E[\bar f - \hat f] = \bar f - E[\hat f] = 0$ → middle term vanishes. definition of $\bar f$
  7. $= \underbrace{(\bar f - f)^2}_{\text{Bias}^2} + \underbrace{E[(\hat f - \bar f)^2]}_{\text{Var}}$ → total = Bias² + Var + σ²
Worked

(a) E[f̂(x)] = 12, f(x) = 10 → Bias = 12 − 10 = 2. (b) Bias² = 1, Var = 9, σ² = 2 → MSE = 1 + 9 + 2 = 12; Variance dominates → overfitting. (c) Three models predict 9, 11, 13 at x where f = 10: mean = 11 → Bias = 1; Var = ((−2)² + 0² + 2²)/3 = 8/3 = 2.67.

Tradeoff (U-curve): as complexity ↑, bias² ↓ and variance ↑; total error is U-shaped → pick the complexity at the bottom of the validation curve (not where bias = 0). σ² just lifts the whole curve.

In practice: split, cross-validate, learning curves

  • We can't see f, so we estimate generalisation with a validation set. A big train–validation gap → variance; both high → bias.
  • k-fold CV: split the training data into k folds; train on k − 1 folds, validate on the remaining one; repeat k times so every point is validated exactly once. Score = average of the k errors. Each model trains on $n\frac{k-1}{k}$ rows (5-fold on 1000 → 800). Fold scores varying a lot → high variance.
  • Learning curves (error vs training size): high bias → both curves plateau high and close (more data won't help); high variance → big gap that shrinks with more data (more data helps).

Hyperparameter tuning (grid / random search)

Choose hyperparameters by the mean CV score on the training set, refit the winner on all training data, test once. Grid search tries every combination: fits = k × (product of list sizes), e.g. 5 degrees × 4 λ × 5 folds = 100 fits. Random search tries n_iter sampled combinations: fits = k × n_iter; usually as good with far fewer fits. Search λ on a log scale; put scalers inside a Pipeline (no leakage).

⚠ Exam traps
  • MSE = Bias² + Var + σ² (bias is squared; variance is not).
  • Irreducible error can't be reduced by a more complex model.
  • An underfit model is stable (low variance) — consistently wrong.

10Feature Selection

Big idea: keep the original columns that actually help and drop the rest → less overfitting, faster training, easier explanation. (Selection keeps columns; PCA creates new ones.)

Why: the curse of dimensionality

Grid cells $$\#\text{cells} = b^{p} \qquad (b \text{ bins per feature},\ p \text{ features})$$

b = 10, p = 6 → 10⁶ cells. The data can't fill them: most cells are empty, so points are far apart and models overfit. It's bᵖ, not p × b.

Filter methods (score each feature with a simple rule — no model training)

  1. Duplicate columns → drop copies.
  2. Variance threshold → drop near-constant columns. $\text{Var} = \frac1n\sum(x_i - \bar x)^2$; for a 0/1 feature with fraction q of ones, $\text{Var} = q(1-q)$ (10% ones → 0.1 × 0.9 = 0.09). Variance ≠ relevance (a student ID has huge variance and no meaning); variance depends on units.
  3. Pearson correlation with the target → keep features with large |r|.
  4. Correlation between inputs → from a pair with |r| ≈ 1, drop one (redundant).
Pearson correlation $$r = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i - \bar x)^2}\,\sqrt{\sum(y_i - \bar y)^2}} \in [-1, 1]$$
Worked: r = 0 although y depends perfectly on x

x = −2, −1, 0, 1, 2 and y = x² = 4, 1, 0, 1, 4. x̄ = 0, ȳ = 10/5 = 2.

  1. (x − x̄)(y − ȳ): (−2)(2) = −4, (−1)(−1) = 1, (0)(−2) = 0, (1)(−1) = −1, (2)(2) = 4.
  2. Sum = −4 + 1 + 0 − 1 + 4 = 0 → r = 0.

Pearson only sees linear relationships — a correlation filter would wrongly drop x. (r = 0 does not mean independent.)

Normal case: x = 1, 2, 3 and y = 2, 4, 7 → Sxy = 5, Sxx = 2, Syy = 12.667 → r = 5/√(2 × 12.667) = 0.993.

11Principal Component Analysis (PCA)

Big idea: rotate the axes so the first new axis (PC1) points along the direction of greatest spread (variance), PC2 the next greatest at right angles, …. Keep the top k → fewer dimensions with most of the information (information = variance). PCA is unsupervised (never uses y) and builds new features (extraction), unlike selection.

Steps

  1. Centre: $X_c = X - \mathbf 1\boldsymbol\mu^T$ (subtract each column's training mean → every column has mean 0). Standardise too if units differ (cm vs ₹), otherwise the big-unit feature dominates PC1.
  2. Covariance matrix: $S = \frac{1}{n-1}X_c^TX_c$ (p × p, symmetric: $S_{jk} = S_{kj}$; diagonal = variances).
  3. Eigen-decomposition: solve $S\mathbf v = \lambda\mathbf v$. Eigenvectors v = PC directions (unit length, orthogonal); eigenvalues λ = variance along each PC.
  4. Sort λ descending; keep the top k eigenvectors $W_k$.
  5. Project: $Z = X_cW_k$ (n × k scores).
Derivation — variance along a direction is uᵀSu, and the best u is an eigenvector
  1. Projection of a centred point onto a unit vector u: $z_i = \mathbf u^T\mathbf x_i$ the coordinate of the point along u (u must have length 1)
  2. Mean of the $z_i$ = 0 (data centred), so $\text{Var}(z) = \frac{1}{n-1}\sum z_i^2$
  3. $= \frac{1}{n-1}\sum (\mathbf u^T\mathbf x_i)(\mathbf x_i^T\mathbf u) = \mathbf u^T\Big[\frac{1}{n-1}\sum\mathbf x_i\mathbf x_i^T\Big]\mathbf u = \mathbf u^TS\mathbf u$ $z_i^2 = z_i\cdot z_i$ and a number equals its transpose; u comes out of the sum
  4. Maximise $\mathbf u^TS\mathbf u$ subject to $\mathbf u^T\mathbf u = 1$ (Lagrange): $\frac{\partial}{\partial\mathbf u}[\mathbf u^TS\mathbf u - \lambda(\mathbf u^T\mathbf u - 1)] = 2S\mathbf u - 2\lambda\mathbf u = 0$ identity 3 from Topic 4, twice
  5. $\Rightarrow S\mathbf u = \lambda\mathbf u$ → u must be an eigenvector; then Var = $\mathbf u^TS\mathbf u = \lambda\mathbf u^T\mathbf u = \lambda$ → the largest eigenvalue's eigenvector gives the most variance = PC1.
PCA formulas $$|S - \lambda I| = 0 \ \ (\text{2×2: } \lambda^2 - \text{tr}(S)\lambda + \det S = 0) \qquad \text{EVR}_j = \frac{\lambda_j}{\sum_\ell\lambda_\ell} \qquad \sum_j\lambda_j = \text{trace}(S)$$
Worked: points (2,1), (3,3), (4,5)
  1. Mean = (3, 3). Centred: (−1, −2), (0, 0), (1, 2).
  2. $S = \frac{1}{2}\begin{bmatrix}1+0+1 & 2+0+2\\ 2+0+2 & 4+0+4\end{bmatrix} = \begin{bmatrix}1&2\\2&4\end{bmatrix}$ entry (j,k) = Σ(product of centred column j and column k)/(n − 1)
  3. trace = 5, det = 1·4 − 2·2 = 0 → $\lambda^2 - 5\lambda + 0 = 0$ → λ = 5, 0.
  4. Eigenvector for λ = 5: $(1 - 5)v_1 + 2v_2 = 0$ → $v_2 = 2v_1$ → v = (1, 2)/√5 = (0.447, 0.894). normalise to length 1
  5. EVR(PC1) = 5/(5 + 0) = 100% (the points lie on a line → 1-D is lossless).
  6. Score of (−1, −2): z = (−1·1 − 2·2)/√5 = −5/√5 = −2.236.

Another: S = [[3,1],[1,3]] → λ² − 6λ + 8 = 0 → λ = 4, 2; PC1 = (1,1)/√2, EVR = 4/6 = 66.7%.

Choosing k, and limits

  • Cumulative EVR: smallest k reaching the target (e.g. ≥ 90%). λ = 6, 2, 1, 0.5 → 63.2%, 84.2%, 94.7% → k = 3. Scree plot: λ vs component; look for the elbow.
  • Reconstruction: $\hat X_c = ZW_k^T$; the top-k PCs give the smallest reconstruction error (same as maximum variance).
  • PC scores are uncorrelated ($\text{Cov}(z_r, z_s) = 0$) but not necessarily independent.
  • When PCA fails: a low-variance direction can be the predictive one (it's unsupervised); curved structure (linear PCA can't unroll it); unscaled features; outliers. Fitting PCA before CV = leakage.
  • SVD route (what sklearn does): $X_c = U\Sigma V^T$ → directions = columns of V, $\lambda_j = s_j^2/(n-1)$, scores = UΣ.
⚠ Exam traps
  • np.linalg.eigh returns eigenvalues in ascending order — reverse before picking the top k.
  • Eigenvector sign is arbitrary (v and −v are the same PC).
  • Eigenvalue = variance (not std). sklearn PCA centres but does not standardise.

12Regularization (Ridge L2, Lasso L1, Elastic Net)

Big idea: overfitted models have huge coefficients (a slope of 4500 swings ŷ wildly for a tiny change in x). Add a penalty on coefficient size to the loss → smaller, calmer coefficients → a bit more bias, much less variance.

Penalised losses $$\text{Ridge: } \sum(y_i - \hat y_i)^2 + \lambda\sum_{j\ge1}w_j^2 \qquad \text{Lasso: } \sum(y_i - \hat y_i)^2 + \lambda\sum_{j\ge1}|w_j|$$

λ ≥ 0 sets the strength (λ = 0 → OLS; λ → ∞ → all slopes → 0, a flat line = underfit). The intercept is not penalised.

Derivation — Ridge slope in 1-D
  1. Same trick as OLS: $c = \bar y - m\bar x$, so with $a_i = x_i - \bar x$, $b_i = y_i - \bar y$: $E(m) = \sum(b_i - ma_i)^2 + \lambda m^2$
  2. $\frac{dE}{dm} = -2\sum a_ib_i + 2m\sum a_i^2 + 2\lambda m$ OLS part from Topic 3, plus the derivative of λm² = 2λm
  3. Set to 0: $m\left(\sum a_i^2 + \lambda\right) = \sum a_ib_i$
  4. $\boxed{m_{\text{ridge}} = \dfrac{S_{xy}}{S_{xx} + \lambda}}$ λ sits in the denominator → m shrinks toward 0 but never reaches exactly 0
Derivation — Ridge normal equation (many features)
  1. $L = (\mathbf y - X\mathbf w)^T(\mathbf y - X\mathbf w) + \lambda\mathbf w^T\mathbf w$
  2. $\nabla L = -2X^T\mathbf y + 2X^TX\mathbf w + 2\lambda\mathbf w$ OLS gradient (Topic 4) + derivative of $\lambda\mathbf w^T\mathbf w$ = 2λw (identity 3 with A = I)
  3. Set to 0: $(X^TX + \lambda I)\mathbf w = X^T\mathbf y$ $\lambda\mathbf w = \lambda I\mathbf w$, then factor out w
  4. $\boxed{\mathbf w_{\text{ridge}} = (X^TX + \lambda I)^{-1}X^T\mathbf y}$ adding λI also makes the matrix invertible even with collinear features
Derivation — Lasso slope in 1-D (why exact zeros)
  1. $E(m) = \sum(b_i - ma_i)^2 + \lambda|m|$. |m| has a kink at 0, so handle m > 0 and m < 0 separately.
  2. Case m > 0 (|m| = m): $\frac{dE}{dm} = -2S_{xy} + 2mS_{xx} + \lambda = 0$ → $m = \frac{S_{xy} - \lambda/2}{S_{xx}}$. the worksheet absorbs the ½ into λ and writes $m = \frac{S_{xy} - \lambda}{S_{xx}}$
  3. Case m < 0 (|m| = −m): $m = \frac{S_{xy} + \lambda}{S_{xx}}$ (worksheet form).
  4. λ is subtracted in the numerator → once λ ≥ |S_xy| the formula would cross 0 and break its own sign assumption → the algorithm stops at exactly m = 0. That's sparsity = automatic feature selection.
Worked: S_xy = 100, S_xx = 50 (OLS m = 2)

  • Geometry: the OLS error ellipses expand until they first touch the constraint region. A circle has no corners → the touch point is rarely on an axis. A diamond has corners on the axes → the touch point is often a corner → a coefficient is exactly 0.
  • Ridge shrinks big coefficients fastest (w = 5000 adds 25,000,000λ to the loss; w = 1 adds only λ).
  • With correlated features, Lasso keeps one arbitrarily; Ridge/Elastic Net share the weight.
  • Elastic Net in sklearn: ElasticNet(alpha, l1_ratio); l1_ratio = 1 → Lasso, 0 → Ridge.
Practice rules

Standardise features first (the penalty depends on scale). Don't penalise the intercept. Choose λ by cross-validation on a log grid (0.001, 0.01, 0.1, 1, 10, 100): train error rises with λ, validation error falls then rises — take the bottom. Logistic regression: the L2 penalty adds 2λβⱼ to the gradient; sklearn's C = 1/λ.

⚠ Exam traps
  • λ in the numerator (Lasso, subtracts → zeros) vs the denominator (Ridge, divides → shrink).
  • Lasso formula going past 0 → answer 0, not the negative number.
  • Ridge adds λI to XᵀX (not to Xᵀy). Ridge increases bias slightly and reduces variance.
  • Overfitting = high variance, low bias.
