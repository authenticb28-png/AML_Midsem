1ML Project Lifecycle — Part 1

Big idea: an ML project is a pipeline of phases. Phases 1–4: Problem definition → Data collection → EDA → Preprocessing. (Part 2 covers phases 5–11.)

Phase 1 — Problem definition (5-step blueprint)

StepWhat it means
1. Understand the problemFind the exact pain point (e.g. premium users cancelling = churn).
2. Set quantifiable goalsA measurable target: "reduce churn by 10% in 2 quarters", not "make it better".
3. Assess ML feasibilityIs ML even needed? Is there data? "Don't use ML" is a valid answer (if a SQL rule solves it).
4. Identify constraintsBudget, latency (<10 ms?), privacy laws (GDPR) — legal limits are constraints.
5. Stakeholder alignmentEveryone agrees what "success" means.
Rigorous problem statement

"Using [data], predict [target] within [time window], achieving [metric ≥ k]."

e.g. "Using clickstream + purchase data, predict which users stop shopping within 3 months."

Sources: SQL warehouses, public repositories (Kaggle, UCI), APIs, web scraping, manual labelling. Garbage In = Garbage Out: the model can't be better than its data.

Phase 3 — Exploratory Data Analysis (EDA)

  • Univariate (1 variable): distribution, mean, median, outliers → histogram, box plot.
  • Bivariate (2 variables): relationship → scatter plot, correlation.
  • Multivariate (many): interactions → correlation heatmap, pair plot.
  • Histogram = one numerical variable; bar chart = categorical counts. Box plot shows the median (not mean).
  • Class imbalance: 95% "no fraud" → a model that always says "no" gets 95% accuracy but catches 0 fraud. Majority accuracy $= n_{\text{majority}}/n$.
Quartiles, IQR, outlier fences $$\text{IQR} = Q_3 - Q_1 \qquad \text{outlier if } x < Q_1 - 1.5\,\text{IQR} \ \text{ or } \ x > Q_3 + 1.5\,\text{IQR}$$

$Q_1$ = median of the lower half, $Q_3$ = median of the upper half (median itself excluded when n is odd).

Worked: fences

Data: 10, 20, 30, 40, 100 (sorted, n = 5). Median = 30 (middle value).

  1. Lower half = 10, 20 → $Q_1 = (10+20)/2 = 15$. Upper half = 40, 100 → $Q_3 = (40+100)/2 = 70$.
  2. $\text{IQR} = 70 - 15 = 55$; $1.5 \times 55 = 82.5$.
  3. Lower fence $= 15 - 82.5 = -67.5$; upper fence $= 70 + 82.5 = 152.5$. Nothing lies outside, so no outlier by this rule (100 is large but inside the fence).

Phase 4 — Preprocessing

(a) Missing values

Mean of a column with gaps uses only the observed values: [2, ?, 4, ?, 9] → mean = 15/3 = 5 → [2, 5, 4, 5, 9].

(b) Inconsistent data

Duplicates (drop), inconsistent spellings/case ("delhi", "Delhi"), mixed units (kg vs g) → standardise.

(c) Feature scaling — 4 scalers

Scaling formulas
$$\text{Min-Max: } x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \in [0,1]$$ $$\text{Z-score: } z = \frac{x - \mu}{\sigma}$$
$$\text{Max-Abs: } x' = \frac{x}{\max|x|} \in [-1,1]$$ $$\text{Robust: } x' = \frac{x - \text{median}}{\text{IQR}}$$

σ here is the population std: $\sigma = \sqrt{\frac1n\sum (x_i-\mu)^2}$ (divide by n). StandardScaler also divides by n.

Worked: scale x = 30 in the column 10, 20, 30, 40, 100
  1. Min-Max: $(30 - 10)/(100 - 10) = 20/90 = 0.222$.
  2. Z-score: $\mu = (10+20+30+40+100)/5 = 200/5 = 40$. Deviations: −30, −20, −10, 0, 60. Squares: 900, 400, 100, 0, 3600 → sum 5000. $\sigma^2 = 5000/5 = 1000$, $\sigma = \sqrt{1000} = 31.62$. $z = (30 - 40)/31.62 = -0.316$.
  3. Max-Abs: $30/100 = 0.3$.
  4. Robust: median 30, IQR 55 (from above): $(30 - 30)/55 = 0$.

Why Robust exists: the outlier 100 squashes Min-Max (all normal values crowd near 0); median and IQR ignore the extreme value.

Who needs scaling? Gradient descent, KNN, SVM, PCA, regularised models. Trees don't. Fit the scaler on train only, then transform test with the same numbers.

N = 5, ids 0–4 → $\lceil \log_2 5 \rceil = \lceil 2.32\rceil = 3$ columns. Cat = 0 = 000, Dog = 1 = 001, Cow = 2 = 010, Hen = 3 = 011, Bird = 4 = 100. (One-hot would need 5.) If ids start at 1, Bird = 5 = 101 still needs 3 bits, but N = 8 would need 4.

⚠ Exam traps
  • JSON / XML = semi-structured.
  • Label-encoding a nominal feature for linear models/KNN invents a fake order ("Red < Green").
  • LabelEncoder on ['low','high','medium'] gives high = 0, low = 1, medium = 2 (alphabetical).
  • EDA comes before preprocessing.

Parameters vs hyperparameters

Key

Parameters are learned during training (weights $w$, intercept $w_0$). Hyperparameters are set before training by you (learning rate α, max_depth, n_estimators, λ, degree, batch size). Hyperparameters are tuned on the validation set, never on the test set.

Phase 5 — Splitting and data leakage

  • Typical split 70 / 15 / 15. Train = learn parameters; validation = choose hyperparameters/model; test = one final, untouched check.
  • Data leakage = information from validation/test (or from the future) sneaks into training → scores look great, real performance is worse.
  • Leak examples: scaling or imputing with the mean of the whole dataset before splitting; tuning on the test set; a feature computed from the target; using future values in time series.
  • Golden rule: split first, then fit every preprocessing step (imputer, scaler, encoder, feature selection) on train only.

Phase 6 & 7 — Feature engineering and baseline

Feature creation: interactions $x_1 \times x_2$, ratios, date parts (day of week), polynomial terms. Baseline: regression → always predict $\bar y_{\text{train}}$; classification → always predict the majority class. A new model is useful only if it clearly beats the baseline.

Phase 8 — The modelling loop

initialise weights → predict (forward) → compute loss → compute gradient → update weights → check convergence → repeat

Loss + update (preview of L5) $$\text{MSE} = \frac1n\sum_{i=1}^{n}(y_i - \hat y_i)^2 \qquad\qquad w \leftarrow w - \alpha\,\frac{\partial\,\text{Loss}}{\partial w}$$

Converged = the loss stops changing (not "loss = 0"). Learning rate too big → overshoots/diverges; too small → painfully slow.

Phase 9 — Offline evaluation and business mapping

Evaluate the locked model on the test set (MAE, RMSE, R² for regression). Then translate into money:

Worked: is the better model worth it?

Baseline MAE = 12, new MAE = 11 (1 unit better). 1 unit of error costs ₹80,000 per farm; 500 farms; training costs ₹15 lakh.

  1. Saving = improvement × cost per unit × volume = $1 \times 80{,}000 \times 500 = ₹4{,}00{,}00{,}000$ (4 crore).
  2. 4 crore ≫ 15 lakh → deploy. Always convert the metric gain into money before deciding.

Phase 10 — Deployment

Save the model (.pkl pickle) → serve via an API (Flask/FastAPI), the cloud (SageMaker, Azure), or the edge (phone/IoT). Batch predictions = periodic, many rows (nightly recommendations); real-time = instant per request (fraud at checkout). Chosen by latency need.

Phase 11 — Post-deployment

  • Model drift: accuracy falls because the world changed (e.g. 2020 pandemic vs a 2010–2019 travel model). The code is fine; the data changed.
  • Monitoring (Prometheus, MLflow) watches live data and metrics.
  • Periodic retraining = on a schedule, regardless of performance. Triggered retraining = when a metric drops below a threshold τ.
  • "Deploy and walk away" is always wrong for ML. The macro loop goes back to the start.
⚠ Exam traps
  • Learning rate is a hyperparameter, even though it controls training.
  • Imputing/scaling before splitting = leakage, even if the model never "sees" test rows.
  • R² can be negative on the test set (worse than predicting the mean).

3Simple Linear Regression (OLS)

Big idea: fit the straight line $\hat y = mx + c$ that makes the sum of squared vertical errors as small as possible. OLS gives the answer in one formula (closed form) — no iteration.

Residuals and choosing the loss

Residual $$e_i = y_i - \hat y_i = y_i - (mx_i + c) \qquad (\text{actual} - \text{predicted, a vertical gap})$$
LossProblem / property
$\sum e_i$ (signed)+ and − errors cancel; total 0 doesn't mean a good fit
$\sum |e_i|$ (absolute)robust to outliers, but has a kink at 0 (not differentiable there) → no clean formula
$\sum e_i^2$ (squared) ✔smooth everywhere, so set derivatives to 0 → closed form. But it amplifies outliers (error 10 counts 100×)
OLS loss (error surface) $$E(m, c) = \sum_{i=1}^{n}(y_i - mx_i - c)^2$$

It is a convex bowl over the (m, c) plane → exactly one lowest point, found where $\frac{\partial E}{\partial m} = 0$ and $\frac{\partial E}{\partial c} = 0$.

Derivation 1 — the intercept c
  1. $E = \sum (y_i - mx_i - c)^2$ start from the loss
  2. $\frac{\partial E}{\partial c} = \sum 2(y_i - mx_i - c)\cdot(-1)$ chain rule: derivative of (stuff)² is 2·stuff·(derivative of stuff); the derivative of $(y_i - mx_i - c)$ w.r.t. c is −1
  3. $-2\sum (y_i - mx_i - c) = 0$ set to zero for the minimum
  4. $\sum y_i - m\sum x_i - \sum c = 0$ divide by −2 and split the sum into three sums
  5. $\sum y_i - m\sum x_i - nc = 0$ c is the same for all n rows, so $\sum c = nc$ (not c!)
  6. $c = \frac{\sum y_i}{n} - m\,\frac{\sum x_i}{n}$ move nc to the right, divide by n
  7. $\boxed{c = \bar y - m\bar x}$ $\frac{\sum y_i}{n} = \bar y$, $\frac{\sum x_i}{n} = \bar x$

Meaning: put $x = \bar x$ in the line: $\hat y = m\bar x + \bar y - m\bar x = \bar y$. The OLS line always passes through $(\bar x, \bar y)$. Also step 3 says $\sum e_i = 0$: residuals sum to zero.

Derivation 2 — the slope m
  1. $y_i - mx_i - c = y_i - mx_i - \bar y + m\bar x$ substitute $c = \bar y - m\bar x$ (this removes c, leaving one unknown)
  2. $= (y_i - \bar y) - m(x_i - \bar x)$ group the y-terms and the m-terms
  3. Let $a_i = x_i - \bar x$ and $b_i = y_i - \bar y$. Then $E(m) = \sum (b_i - m a_i)^2$. short names for the deviations from the mean
  4. $\frac{dE}{dm} = \sum 2(b_i - m a_i)\cdot(-a_i)$ chain rule again; the derivative of $(b_i - ma_i)$ w.r.t. m is $-a_i$
  5. $-2\sum (a_ib_i - m a_i^2) = 0$ multiply out $(b_i - ma_i)(-a_i)$ and set to 0
  6. $\sum a_ib_i = m\sum a_i^2$ divide by −2, move the m-term to the other side
  7. $\boxed{m = \dfrac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2} = \dfrac{S_{xy}}{S_{xx}} = \dfrac{\text{Cov}(x,y)}{\text{Var}(x)}}$

Minimum check: $\frac{d^2E}{dm^2} = 2\sum a_i^2 > 0$ → bowl opens upward → minimum.

OLS recipe

① $\bar x, \bar y$ → ② $a_i = x_i - \bar x$, $b_i = y_i - \bar y$ → ③ $S_{xy} = \sum a_ib_i$, $S_{xx} = \sum a_i^2$ → ④ $m = S_{xy}/S_{xx}$ → ⑤ $c = \bar y - m\bar x$.

Shortcut form: $m = \dfrac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}$ (same answer, no means needed).

Worked: x = 1,2,3,4,5 and y = 2,4,5,4,5 (the course lab)

$\bar x = 15/5 = 3$, $\bar y = 20/5 = 4$.

⚠ Exam traps
  • Compute m first, then c. The denominator is $\sum(x-\bar x)^2$ — x only (it's NOT the covariance).
  • All x equal → $S_{xx} = 0$ → slope undefined (the lab returns [−1.0, −1.0]).
  • Why substitute c first? To reduce 2 unknowns to 1, not because "c must come first in ML".
  • One outlier can swing the slope a lot (squared loss). Absolute loss is the robust one.
  • Two inputs → a plane $\hat y = m_1x_1 + m_2x_2 + c$ (3 parameters). Parameters = features + 1.

4Multiple Linear Regression (OLS)

Big idea: same as SLR but with p features. Write everything with matrices and get the Normal Equation $\boldsymbol\beta = (X^TX)^{-1}X^T\mathbf y$.

Model in matrix form $$\hat y_i = \beta_0 + \beta_1x_{i1} + \dots + \beta_px_{ip} \qquad\Longleftrightarrow\qquad \hat{\mathbf y} = X\boldsymbol\beta$$ $$X = \begin{bmatrix}1 & x_{11} & \cdots & x_{1p}\\ 1 & x_{21} & \cdots & x_{2p}\\ \vdots & & & \vdots \\ 1 & x_{n1} & \cdots & x_{np}\end{bmatrix}_{n\times(p+1)} \quad \boldsymbol\beta = \begin{bmatrix}\beta_0\\ \vdots\\ \beta_p\end{bmatrix}_{(p+1)\times 1}$$

The column of 1s carries the intercept. Sizes: $X^TX$ is $(p+1)\times(p+1)$, $X^T\mathbf y$ is $(p+1)\times 1$ — they do not depend on n. p features → p + 1 parameters.

Derivation — the Normal Equation
  1. $\mathbf e = \mathbf y - X\boldsymbol\beta$ residual vector (n × 1)
  2. $L = \mathbf e^T\mathbf e = \sum e_i^2 = (\mathbf y - X\boldsymbol\beta)^T(\mathbf y - X\boldsymbol\beta)$ eᵀe = sum of squares (a single number). Note eeᵀ would be an n×n matrix — wrong
  3. $= (\mathbf y^T - \boldsymbol\beta^TX^T)(\mathbf y - X\boldsymbol\beta)$ transpose of a difference = difference of transposes; $(X\boldsymbol\beta)^T = \boldsymbol\beta^TX^T$ (order flips)
  4. $= \mathbf y^T\mathbf y - \mathbf y^TX\boldsymbol\beta - \boldsymbol\beta^TX^T\mathbf y + \boldsymbol\beta^TX^TX\boldsymbol\beta$ multiply out like (a − b)(c − d)
  5. $= \mathbf y^T\mathbf y - 2\mathbf y^TX\boldsymbol\beta + \boldsymbol\beta^TX^TX\boldsymbol\beta$ the two middle terms are the same 1×1 number (a number equals its own transpose), so they add up to −2 of it
  6. Use the 3 identities: $\frac{\partial}{\partial\boldsymbol\beta}(\text{const}) = \mathbf 0$,   $\frac{\partial}{\partial\boldsymbol\beta}(\mathbf a^T\boldsymbol\beta) = \mathbf a$,   $\frac{\partial}{\partial\boldsymbol\beta}(\boldsymbol\beta^TA\boldsymbol\beta) = 2A\boldsymbol\beta$ (A symmetric) $\mathbf y^T\mathbf y$ has no β; $\mathbf y^TX\boldsymbol\beta = (X^T\mathbf y)^T\boldsymbol\beta$ so $\mathbf a = X^T\mathbf y$; $A = X^TX$ is symmetric
  7. $\nabla L = \mathbf 0 - 2X^T\mathbf y + 2X^TX\boldsymbol\beta$ differentiate term by term (keep the −2)
  8. $2X^TX\boldsymbol\beta = 2X^T\mathbf y \ \Rightarrow\ \boxed{X^TX\boldsymbol\beta = X^T\mathbf y}$ set the gradient to 0 and divide by 2 — this is the Normal Equation
  9. $\boxed{\boldsymbol\beta^* = (X^TX)^{-1}X^T\mathbf y}$ multiply both sides on the left by $(X^TX)^{-1}$ (if it exists)
Why the identities are true (2 parameters, so you can see it)

Identity 2: $\mathbf a^T\boldsymbol\beta = a_1\beta_1 + a_2\beta_2$. Then $\partial/\partial\beta_1 = a_1$ and $\partial/\partial\beta_2 = a_2$ → the gradient is $(a_1, a_2) = \mathbf a$.

Identity 3: with $A = \begin{bmatrix}p&q\\q&r\end{bmatrix}$: $\boldsymbol\beta^TA\boldsymbol\beta = p\beta_1^2 + 2q\beta_1\beta_2 + r\beta_2^2$. Then $\partial/\partial\beta_1 = 2p\beta_1 + 2q\beta_2$ and $\partial/\partial\beta_2 = 2q\beta_1 + 2r\beta_2$ → that's $2\begin{bmatrix}p&q\\q&r\end{bmatrix}\begin{bmatrix}\beta_1\\\beta_2\end{bmatrix} = 2A\boldsymbol\beta$. This needed A symmetric (both off-diagonals = q). $X^TX$ always is, because $(X^TX)^T = X^TX$.

Worked: fit y = β₀ + β₁x to (0, 1), (1, 2), (2, 6)
  1. $X = \begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix}$, $\mathbf y = \begin{bmatrix}1\\2\\6\end{bmatrix}$.
  2. $X^TX = \begin{bmatrix}1+1+1 & 0+1+2\\ 0+1+2 & 0+1+4\end{bmatrix} = \begin{bmatrix}3&3\\3&5\end{bmatrix}$ top-left = n, off-diagonal = Σx, bottom-right = Σx²
  3. $X^T\mathbf y = \begin{bmatrix}1+2+6\\ 0\cdot1+1\cdot2+2\cdot6\end{bmatrix} = \begin{bmatrix}9\\14\end{bmatrix}$ top = Σy, bottom = Σxy
  4. $\det = 3\cdot5 - 3\cdot3 = 6$; $(X^TX)^{-1} = \frac16\begin{bmatrix}5&-3\\-3&3\end{bmatrix}$ 2×2 rule: swap the diagonal, negate the off-diagonal, divide by det
  5. $\boldsymbol\beta = \frac16\begin{bmatrix}5\cdot9 - 3\cdot14\\ -3\cdot9 + 3\cdot14\end{bmatrix} = \frac16\begin{bmatrix}3\\15\end{bmatrix} = \begin{bmatrix}0.5\\2.5\end{bmatrix}$ → $\hat y = 0.5 + 2.5x$

When the Normal Equation fails

  • $(X^TX)^{-1}$ exists only if the columns of X are linearly independent ($\det X^TX \ne 0$). If a column is an exact combination of others (x₂ = 2x₁, or °C and °F together, or a duplicated 1s column) → singular, no inverse. This is perfect multicollinearity.
  • Cost: inverting a k×k matrix (k = p + 1) by Gauss–Jordan takes 3 nested loops: pivot columns (k) × rows to eliminate (k) × entries in the augmented row (~2k) ≈ $2k^3$ = $O(k^3)$. p = 100 → about 10⁶ operations; doubling p → 8× the cost. That is why gradient descent is used for huge p.
  • Too few rows (n < p + 1) also makes $X^TX$ singular.
⚠ Exam traps
  • Order matters: $(X^TX)^{-1}X^T\mathbf y$, not $X^T(X^TX)^{-1}\mathbf y$.
  • MLR is "linear" because it is linear in the parameters β.
  • NumPy: predictions = X @ theta. sklearn adds the intercept itself (don't add a 1s column there too).
  • Adding a feature never increases training error (it can only stay the same or drop).
