Maths you need (nothing more)
  • Sum: $\sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_n$.   Mean: $\bar x = \frac{1}{n}\sum x_i$, so $\sum x_i = n\bar x$.
  • Derivative rules: $\frac{d}{dx}x^2 = 2x$; $\frac{d}{dx}(a - bx)^2 = 2(a-bx)\cdot(-b)$ (chain rule: outside × inside); $\frac{d}{dx}\ln x = \frac1x$; $\frac{d}{dx}e^{x} = e^{x}$.
  • Minimum of a smooth bowl: set the derivative to 0 and solve.
  • Matrix sizes: $(a\times b)(b\times c) = (a\times c)$. Transpose flips: $(AB)^T = B^TA^T$.
  • 2×2 inverse: $\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ (swap the diagonal, negate the off-diagonal, divide by the determinant).
  • Logs: $\ln(ab) = \ln a + \ln b$, $\ln a^k = k\ln a$, $\ln 1 = 0$, $\ln 2 = 0.693$, $\ln 0.1 = -2.303$.
